## Лабораторная №2 (NoSQL)

### **Вариант №`673`**

Доработать приложение из [лабораторной работы №1](https://github.com/alll1lll1lll/lab1-nosql). Существующие CRUD API и key-value-хранилище должны продолжать работать.

Добавить **MongoDB** для постоянного хранения основных объектов.

Дополнительные параметры
- вложенные данные: **комментарии**;
- связанная коллекция: **организации**;
- индексируемый запрос: **поиск по автору и состоянию**;
- аналитический запрос: **количество объектов по связанным сущностям**;
- изменение структуры: **добавление автора и причины в записи истории**.

### **Требования к программе**
1. Перенести основные объекты в назначенную документоориентированную систему, сохранив CRUD API первой лабораторной.
2. Реализовать назначенные вложенные данные и связанную коллекцию.
3. Добавить фильтрацию, сортировку, пагинацию и поиск по вложенным полям.
4. Транзакционно изменять связанную сущность и одновременно обновлять вложенные данные.
5. Построить aggregation pipeline для назначенного аналитического запроса.
6. Создать составной индекс и сравнить выполнение запроса через explain.
7. Настроить JSON Schema Validation и выполнить повторяемую миграцию существующих документов.
8. Сохранить key-value-хранилище первой лабораторной и использовать его для кэширования запроса к назначенной системе с TTL и инвалидацией.
